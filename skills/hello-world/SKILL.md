# Hello World Skill

This is a demo skill for MilkSU. It provides a `milksu_greet` tool that generates personalized greetings in different styles.

## Usage

Call the `milksu_greet` tool with a `name` parameter and an optional `style` parameter (formal, casual, or pirate).
