# ak-ui 采用计划

关联：[#15](https://github.com/MilkSU-Official/milksu/issues/15)

## 已经确认的事

- 现网拧巴，是因为 Felinic 原子、自研战术/方舟补丁、安全渲染贴片叠在同一窗口。
- 批准稿比现网更戏服，不能当整页实施源。酸绿不再进入产品。
- 成型语言用 ak-ui 的材质（纸面、石墨、青、金）。美学校准参考谷歌 Material 的解读：字号、网格、留白和颜色先造层级；颜色是关系不是戏服；一屏只有一个焦点；表现力只用在当前模块和唯一主操作。
- 功能入口、Desktop RPC 和页面状态机保持原样，只换视觉层。

## 谷歌美学怎么用

不搬 Material 组件。只采用它对「好看」的读法（Material / Material You / M3 Expressive 的同一条线）：

1. **层级先于装饰。** 字号、网格、留白、比例决定先看见什么。切角和衬线只加强已经成立的层级。
2. **颜色是关系，不是涂装。** 一屏一种说话的色。青 = 当前模块 / 主操作；金 = 次级强调；成功绿只表示成功，不再当品牌。
3. **表面说明高度。** 石墨指挥面、纸面事实、青色选中，各管一层。不靠碳纤维、辉光、假遥测堆气氛。
4. **一屏一个焦点。** 表现力只给当前模块和唯一下一步。CTF 是当前题 +「交给 Coding」；Coding 是输入和发送；设置是正在改的那一行。
5. **功能语义不动。** 换皮不改 Desktop RPC、Judge、授权、Pi 工具循环。

酸绿已否决，不映射回产品。

## 本 PR 做什么、不做什么

做：隔离预览、钉死的 ak-ui 0.2.1 CSS、截图；并把生产壳先改一版——全局 token 去酸绿、rail 改命令块、顶栏去掉碳纹。`@yunyoujun/ak-ui` 仍不进 `app/package.json`。

不做：不在本 PR 拆光 Felinic，不改 `current-objectives.md`，不发版。

## 生产接入顺序

用户已确认「先按这一版改」。控件层暂时仍用现有 Vue，先换壳和主操作视觉，再逐页拆 Felinic。

1. **壳（本 PR 已开工）**  
   去酸绿；纸纹/碳纹关掉。Coding 不并排两块指挥台：一级模块轨收回 `4.75rem` 图标栏，会话列表贴在同一条导航表面上。顶栏不再用碳纹。
2. **CTF 题库**  
   表、选中展开、唯一主按钮。验收：打开题库时眼睛先落到当前题和主按钮。
3. **Coding 对话**  
   消息、一条工具行、Composer。不要卷宗、假阶段轨、`FILE NO.`。验收：输入和发送是最重的一块。
4. **设置**  
   分类 + 正在改的那一行。验收：表单不被切角和状态灯抢走。
5. **壳收口**  
   Profile 和其余浮层。CVE 跟 CTF 同构，不单独开刀。

## 硬边界

- 不用官方 Showcase 的角色图、理智条、3D 透视菜单。
- 不把青/黄稀有度色板拿来区分 CTF / CVE / Coding。
- 不在同一 PR 里删掉整个 `@felinic/ui`。某一页的原子不再被引用后，再从该页拿掉。
- Provider Key、Judge、桌面授权、Pi 工具循环都不因换皮改语义。
- 研究页继续不得进入 `vite` 生产 rollup input。

## 退出

第一条生产路径（CTF 表）如果看完仍然抢不过内容，就停，删研究目录，现网保持 Felinic。不要再叠第四套皮肤。
