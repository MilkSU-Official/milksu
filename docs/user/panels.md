# 安全面板

安全面板在对话旁边提供结构化的、领域相关的数据视图。它们是 MilkSU 控制面的展示层，用于投影任务状态、证据、策略决策和 evaluator 结果。

面板本身不是任务事实来源，也不能因为模型写入了“已完成”就判定任务成功。可验证结论应当引用 ToolResult、Artifact 或 Evaluation；面板只负责把这些底层事件呈现给用户。

## 面板工作原理

1. 创建对话时选择一个安全任务类型
2. 代理通过 `panel_update` 工具调用填充结构化数据
3. 通过对话标题栏中的按钮切换面板显示
4. 面板数据随对话持久化保存

## 面板布局

面板浮层覆盖在对话区域的右侧：

```
+------------------------------------------+
| 侧边栏  | 对话区域           | 面板       |
|         |                   | (浮层)     |
|         | [消息...]          | [数据...]  |
+------------------------------------------+
```

底层的对话内容保持全宽显示 -- 面板以浮层形式覆盖，不会挤压布局。

## 数据更新

代理通过 `panel_update` 工具更新面板数据，该工具支持两种操作：

- **set_fields**：替换字段值（例如设置目标、更改阶段）
- **append_items**：向列表字段追加项目（例如添加一个漏洞、添加一个开放端口）

更新是实时的 -- 面板会在代理报告时立即反映变更。

## 面板类型

各面板类型跟踪的具体数据请参见[任务类型](/user/task-types)。
