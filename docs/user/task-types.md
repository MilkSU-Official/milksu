# 任务类型

> 本页描述的是当前已经实现的兼容层，不是 MilkSU 最终的领域架构。现有 `taskType` 同时混入了角色（CTF、渗透测试）、活动（侦察）和能力（逆向），这个早期抽象已经被判定为不够准确。架构目标与迁移 TODO 见[路线图的架构纠偏](/progress/roadmap#架构纠偏-todo-2026-07-16-优先于旧冲刺计划)。

MilkSU 中的每个对话在创建时绑定一个任务类型。任务类型决定了对话旁边可用的结构化面板。

## 对话（默认）

通用对话，无结构化面板。工具结果显示在右侧的 OutputPanel 中。

## 渗透测试

用于渗透测试工作流。面板跟踪以下信息：

- **目标**：IP 地址或主机名
- **阶段**：6 阶段进度（侦察 -> 扫描 -> 枚举 -> 利用 -> 后渗透 -> 报告）
- **漏洞**：已发现漏洞表，含严重程度
- **端口**：开放端口/服务表
- **使用的工具**：所用工具列表

## CTF

用于夺旗赛 (Capture The Flag) 挑战。面板跟踪以下信息：

- **挑战**：名称和描述
- **分类**：Web、Pwn、Reverse、Crypto、Misc 等
- **分数**：挑战分值
- **Flag**：已发现的 Flag 字符串
- **完成状态**：是否已解决

## 侦察

用于网络侦察。面板跟踪以下信息：

- **范围**：目标范围定义
- **主机**：已发现的主机
- **服务**：端口/服务/版本表
- **发现**：值得关注的发现

## 逆向

用于逆向工程分析。面板跟踪以下信息：

- **二进制文件**：被分析的文件
- **架构**：CPU 架构（x86、ARM、MIPS 等）
- **保护机制**：安全措施（NX、Canary、PIE、RELRO），以徽章形式显示
- **函数**：关键函数表
- **发现**：分析结果

## 面板交互

- 对话标题栏中的面板按钮可切换面板显示/隐藏
- 面板从右侧浮层覆盖在对话区域之上（不会改变对话区域的大小）
- 面板数据由代理通过 `panel_update` 工具更新
- 所有面板状态随对话一起持久化保存
