# 用户指南

MilkSU 是一款桌面端 AI 代理 (Agent) 应用，将自由对话与结构化安全任务跟踪相结合。

## 主界面

界面分为三个区域：

- **侧边栏**（左侧）：对话列表，支持搜索、任务类型图标和管理操作
- **对话区域**（中部）：消息、工具结果和子代理卡片
- **任务面板**（右侧，可选）：领域相关的结构化数据浮层

## 创建对话

1. 点击侧边栏的 **+** 按钮，或在欢迎页面直接输入
2. 选择任务类型（默认为"对话"）
3. 从输入栏的下拉菜单选择模型
4. 输入消息并按 Enter 发送

## 任务类型

每个对话在创建时绑定一个任务类型：

| 类型 | 用途 | 面板 |
|------|------|------|
| 对话 | 通用对话 | 无（工具结果显示在 OutputPanel） |
| 渗透测试 | 渗透测试工作流 | 阶段追踪器、漏洞、端口 |
| CTF | 夺旗赛挑战 | Flag、分类、分数、完成状态 |
| 侦察 | 网络侦察 | 范围、主机、服务、发现 |
| 逆向 | 逆向工程 | 二进制分析、保护机制、函数 |

## 语言

在 Settings -> General -> Language 中切换英文和中文。更改立即生效，无需重启。
