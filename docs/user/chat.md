# 对话

## 发送消息

在底部输入栏中输入内容并按 Enter 发送。代理 (Agent) 会以流式文本 (Streaming) 逐字符回复。

## 工具结果

当代理调用工具时，对话中会出现一个可折叠的卡片，显示：
- 工具名称和状态（运行中/已完成/错误）
- 工具输出（可展开查看）

## 子代理结果

当代理为并行任务派生子代理 (Sub-agent) 时，会显示一个分组卡片，包含：
- 子代理数量及其任务
- 每个子代理的流式输出
- 各子代理的完成状态

## 模型选择

输入栏中的下拉菜单可在对话过程中切换模型。模型按提供商分组显示。

## 对话管理

- **搜索**：在侧边栏搜索框中输入，按标题或内容筛选
- **删除**：将鼠标悬停在侧边栏中的对话上，点击 X 按钮
- **新建**：点击 + 按钮或使用欢迎页面
