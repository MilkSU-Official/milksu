# 设置

通过侧边栏的齿轮图标进入设置页面。设置分为 5 个标签页。

## 通用

- **主题**：浅色（默认）。深色模式计划中。
- **语言**：英文或中文。更改立即生效。

## API 密钥

为每个提供商配置 API 密钥：

| 提供商 | 密钥格式 |
|--------|----------|
| DeepSeek | `sk-...` |
| Anthropic | `sk-ant-...` |
| OpenAI | `sk-...` |
| Google Gemini | `AI...` |
| Groq | `gsk_...` |

密钥存储在本地磁盘上，以环境变量的形式传递给代理桥接进程 (Bridge)。密钥不会被传输到提供商 API（或启用中继时的中继服务）之外的任何服务。

## 中继

启用中继模式 (Relay Mode) 后，所有请求将通过兼容 OpenAI 协议的中继服务转发：

- **启用中继**：全局开关
- **中继 API 密钥**：中继服务的认证密钥
- **中继 URL**：API 端点（默认：ciyuanliudong.com）

中继启用后，各提供商的独立密钥将被忽略。中继服务负责处理认证和请求转发。

## 用量

预估的 Token 用量和费用追踪。包括：
- 按提供商统计的 Token 数量
- 会话统计
- 实时指标（占位）

## 关于

应用版本、链接和致谢信息。
