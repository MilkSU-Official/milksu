# 项目管理

项目 (Engagement) 是有时间范围的安全评估项目，用于将相关对话组织在一起。

## 什么是项目？

一个项目代表一次安全评估任务，包含：
- **名称**：项目标识
- **描述**：范围和目标
- **目标系统**：被评估的系统
- **时间线**：开始和结束日期
- **状态**：进行中、已完成或已归档

## 创建项目

使用对话标题栏中的项目选择器来创建或选择项目。每个对话可关联一个项目。

## 项目与任务状态

当对话关联到某个项目后，任务面板的初始状态可从项目数据中自动派生。例如，渗透测试项目会自动填充 PentestPanel 中的目标字段。

## 存储

项目以独立的 JSON 文件存储：
```
~/Library/Application Support/com.milksu.app/engagements/*.json
```
