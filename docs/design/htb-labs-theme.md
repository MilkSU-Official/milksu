MilkSU 保留现有的三段训练流与 Vue / `@felinic/ui` 组件结构。主题改造不增加
首页模块、不把设置塞进训练列表，也不把表格重新做成卡片墙。

## 语义令牌

| 角色 | 值 | 来源 |
| --- | --- | --- |
| 页面背景 | `#101927` | HTB `html/body/main` 计算背景 |
| 导航/顶栏 | `#0D1522` | 在主背景上压暗一级，保留 HTB 深蓝黑关系 |
| 列表/卡片 | `#151F2E` | HTB 题目表格行计算背景 |
| 控件/选中 | `#1E2939` | HTB 搜索框和激活导航计算背景 |
| 边线 | `#212C3C` | HTB 顶栏、侧栏分隔线计算色 |
| 正文 | `#F4F4F4` | HTB 控件与激活文字计算色 |
| 次要文字 | `#8799B5` | HTB 未选标签计算色 |
| 主强调 | `#9FEF00` | HTB Upgrade、进度和重点动作计算色 |

所有业务组件继续只消费 `background`、`card`、`border`、`brand` 等语义角色。
原始色值只存在于 `app/src/index.css` 的主题令牌区。

## 交互约束

- 荧光绿只用于主动作、选中、进度和成功，不把整张卡片染绿。
- 题库与训练记录继续使用列表/表格密度；不堆叠重复卡片。
- Hover/pressed 使用现有中性 overlay 阶梯，深色面上提亮，不制造发光阴影。
- Judge、Rejected、warning 继续使用各自语义色，不用绿色冒充平台成功。
- 窄屏允许工具条换行；题目内容仍由单一滚动区持有。
