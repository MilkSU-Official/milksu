# 桌宠皮肤设计合同

> 文档状态：Current / Authoring contract
>
> 事实审计：2026-09-20
>
> 本页回答「要自己画一款桌宠皮肤，必须交出哪些帧、画在多大的画布上、哪些部位要留给产品」。
> 产品 chrome 仍以仓库根目录 `AGENTS.md` 为准，这里不复述颜色 token。
> 插件槽位 `app.pet` / 权限 `ui.pet` 已接线，见 [插件框架](plugin-framework.md)。设置 → 桌宠可以选文件夹导入，或选已启用的 `app.pet` 插件皮肤。

当前出厂皮肤是 `app/src/assets/companion/idle.png`、`talk.png` 与 `decide.png`。悬浮窗渲染器在 `CompanionPetWindow.tsx`。自定义皮肤按本页交帧，从设置 → 桌宠换上。

## 运动，不是表情包

产品认五个运动名。作者按运动交静止帧，不要在图里写字、画加载圈或叹号。

| 运动 | 产品何时使用 | 作者交什么 | 产品自己叠什么 |
| --- | --- | --- | --- |
| `idle` | 空闲 | **必交**。闭嘴、完整帽子、帽顶偏左有一颗黄色五角星。 | 轻微上下浮动（约 1.1s）。 |
| `talk` | 正在流式说话 | **必交**。与 `idle` 同一张脸和同一顶帽子，嘴微张笑。 | 浮动加快（约 0.28s）。 |
| `think` | 忙碌但还没开口 | 可另交一帧；不交就复用 `idle`（闭嘴）。 | 帽顶加载饰旋转（反向，1.6s / 圈）。 |
| `decide` | 等用户确认，或刚出错 | **必交**。同一张脸，嘴微张惊讶。 | 帽顶黄色叹号；脑袋上方弹出气泡。 |
| `complete` | 这一回合刚说完 | 可另交一帧；不交就复用 `talk`（笑）。 | 帽顶绿色叹号，大约 2.8 秒后回到 `idle`。 |

优先级：`decide` > `talk` > `think` > `complete` > `idle`。`decide` 盖住说话、思考和完成。

不要交这些：眨眼循环、走路循环、APNG / WebP 动画、baked 加载圈、baked 叹号、脸上的罗马音或商标字。帽顶黄星属于 `idle` / `talk`，不是加载饰，也不要求思考圈或叹号盖住它。产品不会播序列帧；眨眼以后若要加，也是可选增强，不是合同。

## 画布

活窗口就是角色本身：`160 × 160` CSS 像素，没有多余的透明边，免得看不见的窗口压住下面 App 的按钮。源图建议 `480 × 480` PNG（RGBA），`object-fit: contain` 缩进这个方框。决策气泡由产品叠在角色上方，作者不用留空。更大也可以，但不要改比例去撑满窗口。

```text
       160
+------------------+
| [决策气泡，最多两行] |  产品叠在角色上方
|       角色        |
|                  |
+------------------+ 160
```

要求：

- 背景必须是真透明。不要靠「抠掉白色」：白裙子和浅帽沿会被挖穿。
- 角色完整落在这个方框里，脚底靠近盒底，头顶不要顶死上沿（帽顶饰要占约 26% 边长）。
- PNG 里不要画对话框、HUD 或按钮。
- 三端同一套图。不要为某个 OS 另出一版。

## 必交关键帧

### `idle.png`（锁定帧）

这是整套皮肤的锁。后面所有帧都从它长出来，不要重抽一张「同角色」。

- 全身可见，正面或 3/4 正面，站定。
- 帽子画完整。帽顶偏左要有一颗黄色五角星；不要画成四角闪，也不要留缺口等产品补花。
- 不要把加载圈或叹号画进 PNG。思考和决策叠层锚在帽顶附近，不必盖住这颗星。
- 嘴闭合。
- 发色、帽色、光影在整套里锁定。不要一张有阴影、下一张没阴影。

出厂默认就是这一条：白发、猫耳、蓝色光滑帽、帽顶偏左黄五角星、蓝眼、白裙。帽沿不要另加一圈碎星。

### `talk.png`

- 从 `idle` 只改嘴（微张笑，说话和完成共用）。
- 帽子、耳朵、头发、衣服、光影必须还能对上 `idle`。
- 不要为了「更像在说话」去改帽色或补帽沿星星。

### `decide.png`

- 从 `idle` 只改嘴（微张惊讶）。
- 帽子、耳朵、头发、衣服、光影必须还能对上 `idle`。
- 不要把黄色叹号画进 PNG。

做不到整张重画时，允许在 `idle` 上只嫁接嘴部。

## 产品叠层（黄星留下，加载圈和叹号不要画）

帽顶饰锚在角色盒里：圆心约 `(50%, 24%)`，边长约角色盒的 `26%`。也就是帽子最高点附近，不是脸。

| 运动 | 叠层 | 作者必须留空的原因 |
| --- | --- | --- |
| `idle` | 无 | 只露帽顶偏左的黄五角星。 |
| `talk` | 无 | 同上。 |
| `think` | SVG 加载饰，反向旋转 | 不要再画一圈加载。叠层不必盖住黄星。 |
| `decide` | 黄色 SVG 叹号 + 窗口顶部气泡 | 不要把叹号或对话框画进 PNG。气泡在角色之上，不要让帽子挡住文案。 |
| `complete` | 绿色 SVG 叹号 | 不要把绿色叹号画进 PNG。 |

气泡由产品用当前界面语言填写，例如「有一条命令在等你确认」。作者不要把文案画进皮肤。

以后若某套皮肤自带 `think.png` / `complete.png`，仍然不要把加载圈或叹号画死在帽子上，除非它同时声明关闭产品叠层。默认皮肤走叠层，思考复用 `idle`，完成复用 `talk`。

## 自定义包

设置 → 桌宠 → 皮肤默认是 Milk。选「添加皮肤」指向下面这个文件夹，或启用带 `app.pet` / `ui.pet` 的插件：

```text
my-companion-skin/
  skin.json
  idle.png
  talk.png
  decide.png
  think.png      （可选）
  complete.png   （可选）
```

`skin.json`：

```json
{
  "api": "milksu.companion-skin/v1",
  "id": "example.default",
  "name": { "zh": "默认", "en": "Default" },
  "sprite": { "width": 148, "height": 148 },
  "mark": { "cx": 0.5, "cy": 0.24, "size": 0.26 },
  "frames": {
    "idle": "idle.png",
    "talk": "talk.png",
    "decide": "decide.png"
  },
  "overlay": {
    "think": "spin",
    "decide": "bang",
    "complete": "bang"
  }
}
```

规则：

- `api` 必须是 `milksu.companion-skin/v1`。
- `frames.idle`、`frames.talk` 与 `frames.decide` 必填，路径只允许包内相对文件名。
- `frames.think` / `frames.complete` 可省略；思考省略时复用 `idle`，完成省略时复用 `talk`，并仍用 `overlay`。
- `overlay.think`：`spin` 或 `none`。`overlay.decide` / `overlay.complete`：`bang` 或 `none`。
- `name` 必须中英成对。不要把说明、作者故事或「这不是官方皮肤」写进产品气泡。
- 图片：PNG，RGBA，建议 480×480，单张不超过 2 MiB，边长不超过 1024。不要 JPG 白底。
- 插件若走 `app.pet` 槽位，Manifest 必须带 `ui.pet`。启用后设置里会出现这套皮肤；宿主读包根目录的 `skin.json` 和帧。

缺帧时的回退：没有 `talk` 或 `decide` 就不要发布；没有 `think` 用 `idle` + 叠层，没有 `complete` 用 `talk` + 绿色叹号。不要静默拿一张完全不同的脸去补。

## 验收（对着跑起来的悬浮窗看）

1. 空闲：只有角色在轻轻浮动，闭嘴，帽顶偏左能看见黄色五角星。
2. 发一句让桌宠说话：切到微笑张嘴，帽子和头发没有换色、没有多出星星。
3. 让它忙起来但还没流式输出：仍是闭嘴，帽顶加载饰在转，且转的方向是顺时针看去的反方向（CSS `rotate(-360deg)`），速度大约 1.6 秒一圈。黄星可以露在加载饰旁边。
4. 触发跨会话确认或让它报错：切到惊讶嘴，帽顶变成黄色叹号，气泡完整停在脑袋上方，帽子和头发不得盖住字。
5. 回合说完：切到微笑，帽顶绿色叹号大约 2.8 秒，然后回到空闲闭嘴。
6. 右键角色：弹出菜单（对话 / 隐藏桌宠 / 打开主窗口 / 桌宠设置 / 退出），不要直接藏起来。macOS Dock 右键和 Linux 托盘右键是同一组动作。对话打开圆角手机窗（角色先收起），不是主窗口里的整页，也不和角色并排。隐藏之后，macOS Dock 或 Windows 任务栏（Linux 托盘）还能唤醒。这是壳行为，不是皮肤的一部分。

不要用挂载测试去锁 class 名或 PNG 哈希。换默认皮肤时，更新本页出厂描述，并替换 `app/src/assets/companion/` 那三张图。
