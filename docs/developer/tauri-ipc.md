# Tauri IPC

## 双通道通信

Tauri v2 提供两种 IPC 机制：

### invoke（请求-响应）

前端调用后端命令并等待返回结果。类似于 HTTP POST。

```typescript
// Frontend
const result = await invoke("send_message", {
  conversationId: "abc",
  prompt: "Hello"
});

// Backend (Rust)
#[tauri::command]
async fn send_message(
  conversation_id: String,
  prompt: String,
  state: State<'_, BridgeState>,
) -> Result<(), String> {
  // Write to bridge stdin
}
```

### emit/listen（事件推送）

后端向前端推送事件。类似于 WebSocket 消息。

```rust
// Backend
app_handle.emit("agent-message", AgentMessage {
  id: conversation_id,
  msg_type: "text_delta".into(),
  content: Some("Hello".into()),
})?;
```

```typescript
// Frontend
listen("agent-message", (event) => {
  const msg = event.payload as AgentMessage;
  // Accumulate into chat messages
});
```

## 可用命令

| 命令 | 方向 | 用途 |
|------|------|------|
| `send_message` | 前端 -> 后端 | 发送用户提示到代理 |
| `get_settings` | 前端 -> 后端 | 从磁盘加载设置 |
| `save_settings` | 前端 -> 后端 | 持久化设置到磁盘 |
| `load_conversations` | 前端 -> 后端 | 加载所有对话 |
| `save_conversation` | 前端 -> 后端 | 保存单个对话 |
| `delete_conversation` | 前端 -> 后端 | 删除对话文件 |
| `create_engagement` | 前端 -> 后端 | 创建新任务 |
| `list_engagements` | 前端 -> 后端 | 列出所有任务 |
| `get_engagement` | 前端 -> 后端 | 获取单个任务 |
| `update_engagement` | 前端 -> 后端 | 更新任务 |
| `delete_engagement` | 前端 -> 后端 | 删除任务 |

## 可用事件

| 事件 | 方向 | 用途 |
|------|------|------|
| `agent-message` | 后端 -> 前端 | 聊天消息流式传输 |
| `panel-update` | 后端 -> 前端 | 任务面板状态更新 |
| `subagent-delta` | 后端 -> 前端 | 子代理流式输出 |
| `subagents-done` | 后端 -> 前端 | 所有子代理已完成 |
| `bridge-error` | 后端 -> 前端 | 桥接进程错误 |

## 能力与权限

Tauri v2 要求显式的能力声明 (Capability Declarations)：

```json
// capabilities/default.json
{
  "permissions": [
    "core:default",
    "core:event:default",
    "shell:allow-open"
  ]
}
```

每个 IPC 命令必须有对应的权限条目。自动生成的权限清单位于 `permissions/autogenerated/` 目录。

## 浏览器预览桩

为了在无 Tauri 环境下进行开发，`tauri.ts` 提供了基于 localStorage 的桩实现：

```typescript
export async function invokeCommand(cmd: string, args: Record<string, unknown>) {
  if (typeof window.__TAURI__ !== "undefined") {
    return invoke(cmd, args);  // Real Tauri
  }
  // Fallback: localStorage stubs
  switch (cmd) {
    case "get_settings": return getLocalSettings();
    case "save_settings": return saveLocalSettings(args);
    // ...
  }
}
```

这使得 `npm run dev` 可以在任意浏览器中运行，用于 UI 开发。
