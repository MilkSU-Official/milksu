# MilkSU Wiki

Wiki 用树形词条解释文档中反复出现的概念。它不决定产品目标，也不记录开发进度；发生冲突时，以[能力边界](/developer/security-agent-boundary)和[核心架构](/developer/architecture)为准。

## 概念入口

- [两种“安全”](/wiki/two-securities)：Agent Security 与 Agent for Security。
- [运行时词典](/wiki/runtime-glossary)：Job、Attempt、Evidence、Effect、Evaluator 等核心名词。
- [项目关系词典](/wiki/project-relations)：接入、外部 Worker、学习、Benchmark 和拒绝分别是什么意思。

## 为什么只保留这棵树

Wiki 不承担用户指南或进度页职责，只解释反复使用的概念；当前事实和目标由[文档状态登记](/developer/document-status)、
[当前目标](/developer/current-objectives)、代码、测试和 Git 历史决定。当前 GitHub Latest Release 是 `v26.904.1`。
