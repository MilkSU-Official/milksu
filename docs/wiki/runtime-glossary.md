# 运行时词典

| 词 | 人话解释 |
| --- | --- |
| Engagement | 一次被授权的工作范围：谁允许、可以碰什么、何时到期 |
| Job | 一个有明确结果的安全任务 |
| Attempt | 在固定模型、工具、环境和预算下的一次尝试 |
| Step | 可提交、可恢复的最小推进单元 |
| Action | 对工具或环境的结构化调用 |
| Observation | 工具或目标返回的原始事实 |
| Artifact | PoC、脚本、补丁、流量、样本、日志等可保存产物 |
| Evidence | 用于支持结论的 Observation 或 Artifact 引用 |
| Effect | 对外部世界造成的创建、修改、删除、发送或权限变化 |
| Evaluator | 不听模型自评、独立检查结果的程序或规则 |
| Outcome | Evaluator 和人工复核共同形成的最终结果 |
| Trace | 串起模型调用、工具动作、证据和结果的时间记录 |
| Recovery | 从已提交状态继续运行，并避免重复副作用 |

完整对象关系见[六层运行时架构](/developer/architecture#核心对象模型)。
